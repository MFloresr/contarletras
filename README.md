contarletras
============

Programa en Java que cuenta cuántas veces aparece cada letra (a-z y A-Z,
distinguiendo mayúsculas de minúsculas) en una frase introducida por el usuario.

## Uso

```
javac -d bin principal.java
java -cp bin cuentaletras.principal
```

Al ejecutarlo, escribe una frase cuando se te pida y el programa imprime cuántas
veces sale cada letra repetida.
